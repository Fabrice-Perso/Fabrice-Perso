# 👋 Bonjour, je suis Fabrice Magnan de Bellevue

### Développeur Web Full Stack • PHP / Laravel • Next.js / TypeScript

Passionné par le développement web et les applications métier, je conçois et maintiens des applications web complètes allant du frontend jusqu'au backend.

Application web de gestion financière développée avec :

- Laravel 12
- PHP 8.2
- Next.js 15
- TypeScript
- MySQL
- Zustand
- Tailwind CSS

### Fonctionnalités principales

- Comptabilité personnelle
- Comptabilité professionnelle
- Gestion ASL
- Facturation
- Déclarations fiscales
- Budgets & projections
- Statistiques financières
- Support & administration

### Architecture

- API REST Laravel
- Frontend Next.js
- Authentification Sanctum
- Actions / Services / Orchestrators
- Jobs & Queues
- Gestion des releases et du changelog
- GitHub Actions
